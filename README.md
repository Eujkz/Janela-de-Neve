# ❄️ Janela de Neve

### Um inverno personalizado na sua área de trabalho!

**Janela de Neve** é uma versão modificada do Snowhush, desenvolvida para oferecer novos efeitos climáticos, personalização avançada e suporte ao português brasileiro no Windows.

## ✨ Funcionalidades

- ❄️ **Neve nas janelas:** efeitos de acumulação sobre as janelas do Windows.
- 🌨️ **Física aprimorada:** neve com acúmulo irregular e movimento ao arrastar janelas.
- 🌪️ **Tempestades:** controle de intensidade, vento e rajadas.
- 🌸 **Estações do ano:** modos de neve, chuva, outono e primavera.
- 🖱️ **Interatividade:** efeitos que reagem ao movimento do cursor.
- 🎨 **Personalização:** ajustes de velocidade, tamanho, densidade, cor e limite de acumulação.
- 🇧🇷 **Português brasileiro:** interface e menus traduzidos.

## 💻 Compatibilidade

- Windows 10 e Windows 11
- Sistemas de 64 bits

## 📥 Download
